# Howdy 🤠

I'm Chris. By day I lead technical customer success for Linux, Kubernetes and AI at an enterprise vendor. Nights and weekends I build things in St. Pete, Florida, and run them on bare-metal Kubernetes that I own end to end.

Lately that means small tools, mostly for people who run AI coding agents. They live under [Land O’ Clusters](https://github.com/Land-o-Clusters). Each one tries to show its work, down to where a number came from and why one is missing.

## What I'm building

- [Floati](https://github.com/Land-o-Clusters/floati) gives a fleet of local coding agents one bus and one board, whichever harness each agent runs in. It's an early public cut for macOS.
- [sleight](https://github.com/Land-o-Clusters/sleight) lets Claude Code drive Mac apps in the background through the computer-use engine bundled with the ChatGPT desktop app, so your cursor stays yours.
- [logijuice](https://github.com/Land-o-Clusters/logijuice) puts the battery levels of Logitech gear on a Logi Bolt receiver in your menu bar and warns you before anything dies.
- Puddle is a menu-bar city that meters your AI agents, down to how much water they theoretically drink. It isn't out yet. [@puddlectl](https://twitter.com/puddlectl) will say when.
- RoleGauge keeps a dated record of what employers post and scores it the same way every time. It's in private development.

## How I work

AI agents write most of my code, each in its own lane, all talking over one bus. An architect agent makes the final call, a red team tries to break the work, and I run the operation. I don't trust a test until I've watched it fail, and I want the same input to give the same answer every time. The hard bugs usually turn up when I question the evidence behind a result. It's a beautiful world where smell counts as much as code-vision.
